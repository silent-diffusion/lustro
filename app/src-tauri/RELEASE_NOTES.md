## What's new in Lustro 0.1.0
- **First desktop release.** Scan a drive or a folder and watch the folder tree grow live.
- **Explore** with the block map, ring chart, file tree and 3D terrain.
- **What grew** compares each scan with the previous one.
- **Cleanup** is a review queue: everything goes to the Recycle Bin, and you can undo it.
- Cloud files from every provider show whether they are cloud only, downloaded or always kept on this device.

## Privacy
Lustro works offline. The only network request is the update check, which you can turn off in Settings. Every update is signed, and Lustro checks the signature before installing.
